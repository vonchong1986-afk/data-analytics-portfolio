## Proyectos

### Proyecto 01 — Análisis de popularidad de lenguajes de programación (TIOBE 2026)
- **Problema**: ¿Cuál es el lenguaje de programación más utilizado en 2026?
- **Datos**: Índice TIOBE, septiembre 2026.
- **Herramientas**: Python, Pandas, Matplotlib.
- **Hallazgo principal**: Python lidera con 17.76%, pero con matices metodológicos.
