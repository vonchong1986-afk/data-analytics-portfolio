# Proyecto 01 — Análisis de popularidad de lenguajes de programación

## Problema

¿Cuál es el lenguaje de programación más utilizado en la actualidad?

## Hipótesis

Python.

## Datos

Índice TIOBE, septiembre 2026.

## Metodología

1. Obtención de datos del índice TIOBE.
2. Análisis descriptivo de los lenguajes del top 7.
3. Análisis crítico de la metodología de la fuente.

## Hallazgos

- Python lidera con 17.76% de rating.
- Caída de 8.22 puntos respecto al año anterior.
- La caída puede estar influida por el uso de IA generativa, que reduce las búsquedas que TIOBE mide.

## Conclusión

Python sigue siendo el lenguaje más popular, pero el índice TIOBE mide búsquedas, no uso real. La IA está reduciendo esas búsquedas, por lo que el liderazgo de Python podría ser más sólido de lo que el índice refleja.
